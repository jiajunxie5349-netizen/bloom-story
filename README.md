# FloraVerse Bloom Story 第一章鍵鼠體驗版

## 第七輪更新：找到目標，也理解為什麼

主畫面的「新手介紹」、探索時 H、旅途筆記或暫停選單，可重看九頁介紹：操作、找路、三站採樣、水路、清理、土壤、植被及最後驗證。每個工作台先呈現學習目標、核心概念、操作步驟與玩法理由；進入後一次顯示一組判斷，可前後切換，既有草稿保留。完成配置後觀察回饋，再按「完成並返回森林」記錄結果。這是教學模型，採樣指數為虛構相對數值。

- **WASD 或方向鍵**移動；**空白鍵**輕跳。輕跳不會越過實體植物或穿過水域。拖曳上下左右轉視角，滾輪縮放。
- **M** 或左上角「林間地圖」展開／收起即時小地圖。藍點是玩家、亮圈是當前任務、葉符號是故事同伴；外圈表示環行林地。
- **J** 或左下角旅途筆記，查看目的地、具體操作、完成條件與可選目標標記。沒有黃色地面引導線。
- **E** 接近可互動物件或故事同伴；提示與按鍵使用相同距離規則，無需對準特定攝影機角度。
- **Esc → 畫面與聲音設定 → 移動節奏**，選慢步、自然或輕快；設定保存在目前瀏覽器。

本章加入守望老樹與受傷的苔光，對話提供環境線索與當前任務。A 位於新增溪流上游，B 位於混濁支流與破袋附近，C 在受影響池岸。擴充外圍地面、環行路線及跨溪木橋，縮小與精靈身體相符的碰撞取樣，外圍植被也重新收束，避免伸入通道。原始 Blender 檔未被覆寫。新增溪流、細葉與蘑菇群、木材／葉脈細節、較柔和的池水反射、圓球懸浮手、種葉 Logo，以及保留即時三維森林背景的暫停視角。

本章仍以「土壤生態與棲地修復」為核心，水路用來連結坡地逕流與池岸問題：

- 證據比對：比較對照、建立來源假說、承認資料限制。
- 水路解謎：區分來源控制、殘留處理與把污染轉移到下游。
- 找物分類：清除人造垃圾、保留自然棲地、未知物交專業處理。
- 地形配置與降雨回饋：理解地表覆蓋、根系與池岸緩衝的不同作用。
- 生境配對：比較光照、水分及排水條件，避免把所有土地種成一樣。
- 新情境排序：將原理轉用，使用可比較的後續觀測檢驗成效。

知識依據：[EPA 養分污染來源](https://www.epa.gov/nutrientpollution/sources-and-solutions)、[EPA 來源與影響的證據鏈](https://www.epa.gov/caddis/nutrients)、[NRCS 地表覆蓋與雨滴沖擊](https://www.nrcs.usda.gov/sites/default/files/2022-12/nrcs144p2_061991_Overview.pdf)、[NRCS 活根與土壤健康](https://www.nrcs.usda.gov/conservation-basics/soil/soil-health/soil-health-on-cropland)。工作台可展開閱讀相應來源。遊戲中的水閘與立即復甦屬藝術化教學，不是自行攔河或污染治理的工程操作指南。

`npm test` 包含全章進度、存檔、任務通行，以及 1,440 個環行步進位置、24 個外圈方向路徑、36 個接近方向互動規則檢查。環行檢查不代表能穿過任何水面、山壁或實體植物。原始幻想植物仍帶有風格化及烘焙材質，美術精修可繼續迭代；目前不宣稱已達寫實攝影品質。其餘章節尚未建置，因此尚未加入它們的正式 NPC。

目前提供種子森林的可玩開發版本：主畫面、獨立章節選單、設定、生態圖鑑，以及證據比對、水路配置、近景清理、土壤配置、植被配置、種子喚醒與綜合驗證。其他章節有視覺預覽與鎖定狀態，尚無可玩的場景。依 2026-10-14 最新指示取消遊玩時長目標，採自由探索、不設倒數與超時失敗。

## 開啟遊戲

在 Cursor 開啟本資料夾。第一次安裝使用 `npm ci`，之後使用 `npm run dev`，開啟終端機列出的 Local 網址。已有 node_modules 時可直接啟動。請透過伺服器開啟，不要直接雙擊 index.html。

`npm test` 執行進度與通行檢查；`npm run build` 產生 `dist/`；`npm run preview` 檢查建置後版本。正式網站需發布 dist 內容，不是直接把 src 上傳作為網頁。Vite 已設定相對路徑，支援 GitHub Pages 的 `/bloom-story/` 子路徑。

## 操作

- WASD 或方向鍵：相機相對方向移動。空白鍵：輕跳。左鍵拖曳：旋轉視角。滾輪：調整距離。
- 按住右鍵：生態透視鏡。僅作觀察輔助，收集樣本按一次 E。
- E：開啟近景互動。點選物件後點目的地，或拖放；可撤銷、提示、檢查方案，Esc 返回探索。
- H：九頁新手介紹。M：即時小地圖。Esc：暫停、設定、安全起點、保存返回與重新開始。
- 這一版尚未包含攝影機辨識與手機觸控移動。

## 章節進度

收齊三處樣本並完成證據比對 15%；水路 20%；清理 15%；土壤 20%；植被 10%；綜合驗證 20%。五項修復達 80% 並完成不加分的喚醒儀式後，第二章顯示已解鎖但仍開發中。全部完成後播放結尾銜接並回主畫面。

任務順序固定，錯誤選擇只提示再試，不扣分。進度保存在目前瀏覽器 localStorage，不會跨瀏覽器、網址或裝置同步。清除網站資料會清除進度；無法存檔時會提示。

## 影片匯入步驟

1. 準備兩支影片，建議 MP4（H.264 影像、AAC 聲音），1920×1080 或 1280×720。先測試目標瀏覽器是否能正常播放。大型影片會增加首次載入時間，依品質需求控制位元率。
2. 在 `public/` 建立 `videos/` 資料夾，把影片命名為 `chapter-01-intro.mp4` 與 `chapter-01-outro.mp4`。
3. 開啟 `src/content.js`，將 films 改為：

```js
export const films = {
  chapter1Intro: 'videos/chapter-01-intro.mp4',
  chapter1Outro: 'videos/chapter-01-outro.mp4',
};
```

4. 路徑不要加開頭斜線，也不要寫成 `public/videos/...`。檔名大小寫必須與實際檔案完全一致，避免 GitHub Pages 找不到。
5. 使用暫停選單的「重新開始本章」測試開場影片。完成回顧後測試結尾影片。影片結束或按「跳過影片」會接續流程；無法自動播放時，按影片播放鍵即可。
6. 影片遺失或格式不支援時會顯示文字銜接，不會卡住遊戲。films 保持空字串時，也使用文字銜接。
7. 確認本機播放正常後重新執行 `npm run build`，再發布更新的 dist。字幕請先製作於影片，獨立 WebVTT 字幕軌尚未加入。

## 場景、效能與驗證範圍

目前使用半徑 34 的擴充林地、高度場與表面碰撞資料。環行路線位於半徑約 30，溪流穿越處有對應木橋；水面、實體植物與陡坡仍不可通行。軟草與薄小葉片可穿行。新增地形後，舊存檔位置會重新選取安全地面，任務成果保留；不會重設正式玩家進度。

主畫面與暫停使用同一個 Three.js 場景。主畫面限制約 30 次繪製／秒，隱藏分頁停止繪製。流暢／均衡／精緻模式分別限制像素比為 1／1.5／1.75，精緻啟用 Bloom 與陰影。水面使用低幅幾何位移、動態法線、漂移水色與接觸漣漪，採不透明即時材質，尚無完整折射或鏡面反射。音效是本機合成的環境與互動原型，並非自然錄音。瀏覽器須在點擊開始後才能啟動聲音。

`npm test` 驗證進度依賴、80% 解鎖、存檔異常、六種解謎完成條件、九處任務可達性、完整環行與互動距離。瀏覽器已驗證九頁介紹、即時地圖、NPC 當前提示、採樣與分步證據操作、水路／清理／土壤／植被／新情境工作台、方向鍵反應與速度選項。這些檢查不代表已完成跨顯示卡或真人全程徒步驗收，不保證所有裝置達固定 FPS。正式劇情影片尚未提供，因此只驗證文字銜接。

開發環境 `?qa=1` 使用獨立存檔與測試定位／復甦預覽；正式建置移除這些工具。`tests/fieldwork.html` 是不寫入正式玩家存檔的工作台驗收頁，亦不納入 dist。

## 程式與資產位置

- `src/main.js`：流程、輸入、設定、教學、NPC 對話、影片及 UI 事件。
- `src/world.js`：Three.js 場景、角色、相機、模型與復甦狀態。
- `src/navigation.js`、`src/interaction.js`：可行走地面、物件阻擋與共同互動距離規則。
- `src/learning.js`：九頁介紹、每種任務的學習目標、概念、操作及來源。
- `src/task-guidance.js`、`src/map-config.js`：當前任務步驟、地圖與實際座標。
- `src/living-world.js`、`src/ground-cover.js`：溪流、木橋、同伴與細小植被。
- `src/puzzles.js`、`src/workbench.js`：解謎條件與教學工作台。
- `src/progress.js`：進度驗證、草稿、儲存及解鎖。
- `public/models/forest_refined.glb`、`sprite_guardian_refined.glb`、`terrain.json`、`collisions.json`：正式模型與對應資料。原始模型保留作備援。
- `public/draco/`：隨站點發布的解碼器，不依賴第三方解碼 CDN。

這是場景專用高度場與碰撞控制器，並非完整通用剛體引擎。若替換地形或大植物，必須重新產生高度／碰撞資料，並重新檢查通行；只壓縮 GLB 不會自動減少渲染面數。

## GitHub Pages 發布

儲存庫 Settings → Pages → Build and deployment → Source 使用 GitHub Actions。`.github/workflows/deploy.yml` 在 main 更新時安裝依賴、測試、建置並發布 dist。不要直接發布開發用 src 或根目錄 index.html；套件匯入未建置會造成空白頁。每次更新確認 Actions 的 Publish Bloom Story 成功，再驗證線上版本。

公開說明僅更新本 README；私人企劃文件與 Blender 工作原檔不需上傳。更新程式、匯出的模型與對應資料即可。
