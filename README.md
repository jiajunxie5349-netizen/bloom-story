# FloraVerse Bloom Story 第一、二章鍵鼠初版

## 第十輪：巨葉森林、對話與清楚的入口

第一章增加高處巨型荷葉與菌傘，細莖保留通行空間。紫色異變膜是架空侵擾，依來源及土壤任務逐步退去；原生植物保留。地表改為連續曲面，河岸與通行資料同步調整，河水使用曲線與變化寬度，避免原本折線水帶及硬直網格岸壁。角色葉衣另存柔化模型，加入轉身傾斜與小手慣性。

右上角「旅程選單」可直接暫停、設定與儲存回主畫面，也支援 Esc。左上角葉片地圖按鈕或 M 開關地圖。NPC 改為逐句對話帶，讀完可「記入旅途筆記」；按 J 展開目前目標、步驟、完成條件與歷次線索。筆記使用獨立 `floraverse.story.v1`，不改寫章節任務成果。

主畫面新增第二章直接入口，點章節卡也可進入實際三維溫室；未解鎖時只預覽，正式任務仍需第一章 80% 並喚醒種子。第二章補充葉叢、貼地植被、藤蔓與花床邊緣材質；仍屬程序化場景初版，不宣稱照片級寫實。

第一、二章各預留開場、轉折與結尾影片。`chapter1TurningPoint` 在水路完成後觸發，`chapter2TurningPoint` 在來源處理完成並離開回饋後觸發。沒有影片時使用文字故事銜接，影片不代替任務得分。序章及第三至五章欄位為後續預留，尚未開發場景不會因此變成可玩。

現用資產為 `terrain_v10.json`、`collisions_v10.json`、`sprite_guardian_v10.glb`；舊檔保留。`src/sculpted-ground.js`、`canopy.js`、`lotus.js` 負責第一章曲面與高處植被，`src/story.js` 負責故事文字與對話紀錄，`src/storybook.css` 負責介面外觀。

## 荷葉補回

第一章池岸與淺水邊緣新增 17 組完整荷葉造型，參照原始設計圖的扇形葉片與放射葉脈，以曲面、微捲葉緣與枯舊材質呈現。植株大小獨立於地面，根部貼合地形；池岸葉片高於角色活動高度，只有細莖參與碰撞，避開任務與通行路線。修復前偏灰褐，修復後逐漸轉綠。

## 第八輪更新：獨立地形與光之花園

第一章的地面與植物分開載入：移除合併資產中的漂浮碎片，以完整貼地植物重建森林層次。保留環湖通路、任務周圍空間，碰撞按植被表面生成；外緣以可見土岸與連續森林包圍。葉衣精靈加入微幅彎曲、呼吸與移動慣性，圓球小手獨立輕浮。

第二章「光之花園」提供灰霾溫室、兩位故事同伴、四種教學互動與結尾驗證的可玩初版。第一章 80% 並喚醒種子後解鎖；另有不保存進度的場景預覽。全程自由探索，不設倒數。

## 開啟遊戲

在 Cursor 開啟本資料夾。第一次安裝使用 `npm ci`，之後使用 `npm run dev`，開啟終端機列出的 Local 網址。已有 node_modules 時可直接啟動。請透過伺服器開啟，不要直接雙擊 index.html。

`npm test` 執行進度與通行檢查；`npm run build` 產生 `dist/`；`npm run preview` 檢查建置後版本。正式網站需發布 dist 內容，不是直接把 src 上傳作為網頁。Vite 已設定相對路徑，支援 GitHub Pages 的 `/bloom-story/` 子路徑。

## 操作

- WASD 或方向鍵：相機相對方向移動。空白鍵：輕跳。左鍵拖曳：旋轉視角。滾輪：調整距離。
- 按住右鍵：生態透視鏡。僅作觀察輔助，收集樣本按一次 E。
- E：開啟近景互動。點選物件後點目的地，或拖放；可撤銷、提示、檢查方案，Esc 返回探索。
- H：九頁新手介紹。M：即時小地圖。Esc：暫停、設定、安全起點、保存返回與重新開始。
- 這一版尚未包含攝影機辨識與手機觸控移動。

## 章節進度

收齊三處樣本並完成證據比對 15%；水路 20%；清理 15%；土壤 20%；植被 10%；綜合驗證 20%。五項修復達 80% 並完成不加分的喚醒儀式後，第二章「光之花園」可開始鍵鼠初版體驗。全部完成後播放結尾銜接並回主畫面。

任務順序固定，錯誤選擇只提示再試，不扣分。進度保存在目前瀏覽器 localStorage，不會跨瀏覽器、網址或裝置同步。清除網站資料會清除進度；無法存檔時會提示。

## 影片匯入步驟

1. 每章準備開場、結尾兩支影片，建議 MP4（H.264 影像、AAC 聲音），1920×1080 或 1280×720。先測試目標瀏覽器是否能正常播放。大型影片會增加首次載入時間，依品質需求控制位元率。
2. 在 `public/` 建立 `videos/` 資料夾，把影片命名為 `chapter-01-intro.mp4` 與 `chapter-01-outro.mp4`；第二章使用 `chapter-02-intro.mp4`、`chapter-02-outro.mp4`。
3. 開啟 `src/content.js`，將 films 改為：

```js
export const films = {
  chapter1Intro: 'videos/chapter-01-intro.mp4',
  chapter1Outro: 'videos/chapter-01-outro.mp4',
  chapter1TurningPoint: 'videos/chapter-01-turning.mp4',
  chapter2Intro: 'videos/chapter-02-intro.mp4',
  chapter2Outro: 'videos/chapter-02-outro.mp4',
  chapter2TurningPoint: 'videos/chapter-02-turning.mp4',
};
```

4. 路徑不要加開頭斜線，也不要寫成 `public/videos/...`。檔名大小寫必須與實際檔案完全一致，避免 GitHub Pages 找不到。
5. 第二章開場會於進入章節播放，結尾在祭壇驗證與捧起種子後播放。第一章使用暫停選單的「重新開始本章」測試開場影片。完成回顧後測試結尾影片。影片結束或按「跳過影片」會接續流程；無法自動播放時，按影片播放鍵即可。
6. 影片遺失或格式不支援時會顯示文字銜接，不會卡住遊戲。films 保持空字串時，也使用文字銜接。
7. 確認本機播放正常後重新執行 `npm run build`，再發布更新的 dist。字幕請先製作於影片，獨立 WebVTT 字幕軌尚未加入。

## 場景、效能與驗證範圍

目前使用半徑 35 的擴充林地、高度場與表面碰撞資料。環行路線位於半徑約 30，溪流穿越處有對應木橋；水面、實體植物與陡坡仍不可通行。軟草與薄小葉片可穿行。新增地形後，舊存檔位置會重新選取安全地面，任務成果保留；不會重設正式玩家進度。

主畫面與暫停使用同一個 Three.js 場景。主畫面限制約 30 次繪製／秒，隱藏分頁停止繪製。流暢／均衡／精緻模式分別限制像素比為 1／1.5／1.75，精緻啟用 Bloom 與陰影。水面使用低幅幾何位移、動態法線、漂移水色與接觸漣漪，採不透明即時材質，尚無完整折射或鏡面反射。音效是本機合成的環境與互動原型，並非自然錄音。瀏覽器須在點擊開始後才能啟動聲音。

`npm test` 驗證進度依賴、80% 解鎖、存檔異常、六種解謎完成條件、九處任務可達性、完整環行與互動距離。瀏覽器已驗證九頁介紹、即時地圖、NPC 當前提示、採樣與分步證據操作、水路／清理／土壤／植被／新情境工作台、方向鍵反應與速度選項。這些檢查不代表已完成跨顯示卡或真人全程徒步驗收，不保證所有裝置達固定 FPS。正式劇情影片尚未提供，因此只驗證文字銜接。

開發環境 `?qa=1` 使用獨立存檔與測試定位／復甦預覽；正式建置移除這些工具。`tests/fieldwork.html` 是不寫入正式玩家存檔的工作台驗收頁，亦不納入 dist。

## 程式與資產位置

- `src/main.js`：流程、輸入、設定、教學、NPC 對話、影片及 UI 事件。
- `src/world.js`：Three.js 場景、角色、相機、模型與復甦狀態。
- `src/navigation.js`、`src/interaction.js`：可行走地面、物件阻擋與共同互動距離規則。
- `src/learning.js`：九頁介紹、每種任務的學習目標、概念、操作及來源。
- `src/task-guidance.js`、`src/map-config.js`：當前任務步驟、地圖與實際座標。
- `src/living-world.js`、`src/ground-cover.js`：溪流、木橋、同伴與細小植被。
- `src/puzzles.js`、`src/workbench.js`：解謎條件與教學工作台。
- `src/progress.js`：進度驗證、草稿、儲存及解鎖。
- 第一章：`forest_ground_v8.glb` 與 `forest_vegetation_v8.glb` 分開載入，使用 `terrain_v10.json`、`collisions_v10.json`。舊版資產保留作回復用途。
- 角色：`sprite_guardian_v10.glb` 與 `src/guardian-life.js`；葉衣微幅彎曲、慣性與懸浮小手。
- 第二章：`light_garden.glb`、`src/garden.js`、`garden-world.js`、`garden-data.js`、`garden.css`。
- `public/draco/`：隨站點發布的解碼器，不依賴第三方解碼 CDN。

這是場景專用高度場與碰撞控制器，並非完整通用剛體引擎。若替換地形或大植物，必須重新產生高度／碰撞資料，並重新檢查通行；只壓縮 GLB 不會自動減少渲染面數。

## GitHub Pages 發布

儲存庫 Settings → Pages → Build and deployment → Source 使用 GitHub Actions。`.github/workflows/deploy.yml` 在 main 更新時安裝依賴、測試、建置並發布 dist。不要直接發布開發用 src 或根目錄 index.html；套件匯入未建置會造成空白頁。每次更新確認 Actions 的 Publish Bloom Story 成功，再驗證線上版本。

公開說明僅更新本 README；私人企劃文件與 Blender 工作原檔不需上傳。更新程式、匯出的模型與對應資料即可。

## 第二章：光之花園（鍵鼠初版）

第一章修復達 80% 並喚醒種子後，在「探索章節」點選光之花園。尚未解鎖時可選「先看看光之花園」：僅探索場景與同伴，不保存第二章進度，也不改變解鎖條件。

故事由灰霾遮光的溫室開始，玻璃老藤與流光提供線索。依序完成灰霧觀測台的證據比較、燃燒爐近景物件處理、風路導向與粒子濾材、日光鏡與植物需求，獲得四顆光之種（各 20%）；祭壇的新情境驗證與捧種儀式完成最後 20%。錯誤可重試、沒有倒數。來源停止、風路啟動、光束與植被色調逐步回應任務。

按 J 查看下一地點、操作與完成條件，M 開關溫室地圖，H 查看七頁介紹。靠近約 2.5 公尺內按 E 互動，與面向角度無關。Esc 可暫停、調整速度、音效、返回入口及保存離開。第二章使用獨立存檔 `floraverse.light-garden.v1`，第一章進度保留。

教學依據為 EPA 懸浮微粒、源頭控制及過濾資料，以及 NASA 光合作用／碳循環資料。單次指數與水色／灰霧僅為線索；題目資料是虛構教學指數，不是安全標準。室外較乾淨是本題的條件，不能推論所有情況都應持續開窗；花開不能證明空氣安全。

本版第一章移除合併資產中的漂浮碎片，另建 251 組完整貼地植物並保留寬路線。地面擴展不會放大植物；外圍環狀地表、可見土岸與森林層次遮蔽場景外空間。仍為程序化美術原型，尚非照片級資產與完整通用物理模擬。第二章已有文字故事與影片接入位置，正式影片尚未匯入。

新增測試驗證第二章四項任務、獨立存檔、各站 24 個接近方向、溫室通路，以及森林 251 組植物根部高度；與第一章完整環行及九處任務檢查一併執行。瀏覽器另走完第二章錯誤回饋、四項任務、結尾、返回與重新載入。
