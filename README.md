# FloraVerse｜Bloom Story

第一、二章鍵鼠探索遊戲。第一章為種子森林，第二章為自然灰霾林谷「光之花園」。序章與第三至五章仍在規劃，正式劇情影片尚未匯入。

## 開啟與操作

安裝依賴後執行 `npm run dev`；`npm test` 執行進度、解謎、存檔與通行檢查；`npm run build` 產生發布用 dist。

- WASD 或方向鍵移動；空白鍵輕跳。拖曳轉動視角，滾輪調整距離。
- 靠近互動物件約 2.5 公尺按 E，或點擊畫面中的互動提示；不要求對準特定角度。
- 左上葉片按鈕或 M 開關地圖；J 查看旅途筆記；H 開啟新手介紹。
- 右上「旅程選單」或 Esc 暫停、調整移動速度與音效、回安全起點及儲存回主畫面。
- 三種畫質依裝置調整解析度；第一章精緻模式加入柔光與陰影。音效為本機合成原型，需要使用者點擊後啟動。

目前沒有攝影機辨識或手機觸控移動。沒有倒數時間，答錯可重試。

## 章節與教學

第一章依序比較三站水樣、控制污染來源、整理池岸垃圾、安排土壤修復、配置適合生境的植物，再完成新情境驗證。五項修復達 80% 並喚醒種子後，正式解鎖第二章。主畫面的第二章 3D 預覽可直接觀看場景與拜訪同伴，不保存任務成果或變更解鎖條件。

第二章從自然林緣進入灰霾林谷，守谷老藤與流光提供逐句對話及當前線索。四段任務分別是苔石觀測、焦黑空地的來源與殘留整理、記錄上／下風傳播、整理遮光枯枝並辨認植物需求。最後在光之種根窩完成新情境驗證與捧種儀式。第二章已移除舊溫室、玻璃牆、人工花床、鋪面、燃燒爐、風扇及日光鏡。

風向拼圖記錄觀測，不代表玩家能改變山風；健康植被是棲地，不是萬能濾材。仍冒煙的來源交由守谷者處理，玩家只整理確認安全並冷卻的散落物。即時復甦是故事的時間壓縮，花開不代表空氣安全。教學引用 EPA 懸浮微粒資料及 NASA 碳循環／光合作用資料，各工作台可展開來源。虛構觀測指數不是安全標準，單次觀測不證明唯一原因。

## 存檔與對話

進度保存在目前瀏覽器的 localStorage，不跨裝置、網址或瀏覽器同步；清除網站資料會刪除進度。無法儲存時會提示。

第二章沿用獨立存檔 `floraverse.light-garden.v1`，第一章成果不變。NPC 對話可記入筆記；舊版第二章室內指令仍保留在儲存資料中，但不混入新版林谷筆記。已完成的任務成果不重設，舊位置若不再安全，載入時改放安全地面。

## 第十二輪場景更新

第一章以原始貼圖扇葉重建 50 株高低植株，使用彎曲漸細的葉柄與不規則植叢。枝葉的連接位置與彎莖同步；植被依材質合併後輸出。原始模型與舊版資產保留。

補齊 1,474 筆地形內部缺失高度；碰撞依目前可見植被三角面重建，移除 5,581 個已撤除舊模型的阻擋格。新植物有自己的實際碰撞。加入動態物件後再驗證安全位置，避免舊位置或移動石塊讓角色卡住。地面與植物不共同縮放。

水池使用連續細分水面、實際河床遮罩、低幅水波及動態法線；土壤維持粗糙、無金屬、無環境反射。尚無完整水體折射或鏡面反射。溪流與自然淺灘保持連續河床。

第二章以獨立連續地形、巨葉、曲莖菌叢、地被與外圍森林構成。林谷外緣由起伏林坡呈現，陡坡依實際坡度限制行走；植物碰撞不再沿用隱藏的矩形花床。低葉片使用實際葉面接近檢查。

## 資產與程式

- 第一章：`forest_ground_v8.glb`、`forest_vegetation_v12.glb`、`terrain_v12.json`、`collisions_v12.json`。
- 原始扇葉模板：`original_fan_leaves_v11.glb`；第二章也使用此貼圖資產。
- 角色：`sprite_guardian_v10.glb`、`src/guardian-life.js`，包含葉衣彎曲、呼吸、轉身傾斜及懸浮圓球小手。
- 場景與控制：`src/world.js`、`navigation.js`、`living-world.js`、`ground-cover.js`、`forest-atmosphere.js`。
- 第二章：`src/garden-world.js`、`garden-data.js`、`garden.js`、`garden.css`。
- 劇情、教學、任務與 UI：`src/story.js`、`content.js`、`learning.js`、`task-guidance.js`、`workbench.js`、`ui.js`。
- `public/draco/` 隨網站發布，不依賴第三方解碼 CDN。

高度場與碰撞為本場景專用控制器，並非完整通用剛體引擎。更換大型植物或地形後必須重建對應資料並檢查通行。

## 影片接入

第一、二章各預留 Intro、TurningPoint、Outro。將 MP4/H.264/AAC 檔案放入 `public/videos/`，在 `src/content.js` 的 films 指定相對路徑，例如 `videos/chapter-01-intro.mp4`，不要加 `public/` 或開頭斜線。字幕目前需預先燒錄。

第一章轉折在水路完成後，第二章轉折在來源任務完成且離開回饋後。跳過或結束影片只接續流程，不增加分數。未匯入、缺檔或播放失敗時提供文字銜接。正式影片尚未製作；文字備援不視為影片成品。
