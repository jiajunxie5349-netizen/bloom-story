# 本機場景編輯器

在遊戲專案資料夾雙擊「開啟場景編輯器.cmd」。啟動後開啟 http://127.0.0.1:5194/editor.html 。本機需有 Node.js、專案依賴及 Blender 5.0。編輯器使用獨立入口，完全不讀寫玩家存檔。

1. 從清單選擇植株，或點擊場景中的植株。搜尋可用 `fan`、`sculpture`、`herb` 或編號。
2. 拖曳紅／藍色軸移動，或輸入 X、Z、旋轉角度與大小，再按「套用調整」。放開拖曳後會自動貼地；不能放進深水或世界邊界外。
3. 「查看選中植株」移近鏡頭。背景拖曳旋轉視角，滾輪縮放。「預覽森林修復後」只改變編輯畫面的預覽。
4. 「復原上一步／重做」保留最近 50 步。「重設選中植株」恢復開啟編輯器時該株的位置。
5. 按「儲存正式場景配置」。本機會由可見模型重新烘焙碰撞，檢查任務接近位置及全圖連通。成功才更新 `public/models/scene-layout.json`；失敗保留原配置，畫面顯示原因。
6. 關閉再開啟編輯器，可以確認調整已保存。也可下載配置備份，日後載入後再儲存。備份不包含碰撞，載入時仍需重新烘焙。

## 儲存與發布的區別

儲存更新的是這部電腦的專案檔案。GitHub Pages 為靜態網站，編輯器不會直接修改線上網站，也不會把 GitHub 憑證放入遊戲。

要讓所有玩家看到新配置，將已驗證的 `public/models/scene-layout.json` 一併提交到原本儲存庫並發布。修改模型時，還需同步模型及 `scene-manifest.json`。原本的 GitHub Pages 發布流程會再跑測試及建置。單純調整位置，不必重新上傳模型。

本機儲存會在 `.scene-drafts/` 留下前一版配置及烘焙輸入。此資料夾不會進入正式建置。若要回復舊備份，可透過畫面的「載入配置備份」開啟其中的 previous 檔，確認後再儲存。

## 可調整的範圍

目前支援第一章 204 株主要植株，包括完整的扇葉與葉柄、杯形植體、傘狀植體、尖錐／嫩芽、地生植株與林冠植株。地形、水體、程序草甸、遠景、角色、任務物件與其他章節不在本輪編輯範圍；任務位置保持固定，避免與劇情判定脫節。

## 如何脫離編輯工具

正式建置只以 `index.html` 作為入口，不包含 `editor.html`、TransformControls、編輯器 CSS 或儲存服務。正式版僅讀取模型、清單與場景配置。日後可移除 `authoring/`、`editor.html` 與啟動檔，再從 `vite.config.js` 移除本機外掛，已發布的遊戲配置仍可運作。

碰撞重建需要與模型完全配對的 Blender 來源檔，預設為 `authoring/scene-source.blend`（隨本機編輯器保存，不上傳網站）。也可在啟動前以 `BLOOM_SCENE_BLEND` 指定本機來源檔位置、`BLOOM_BLENDER` 指定 Blender 執行檔。來源檔不需放到公開網站。
